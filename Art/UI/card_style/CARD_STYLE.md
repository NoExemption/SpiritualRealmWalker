# 卡身与边框样式

## 1. 共用方向

以确认的三辰概念图为依据，使用Godot材质重建墨蓝孔雀青卡身、古金细边与普通卡深色镶金标题带，呼应三辰费用图标。罕见/稀有标题带、插图框以及所有类型小牌直接使用该卡的原版稀有度材质，保留原纹理折面与明暗。当前应用于夜游神整个卡池，太阴、星辰、太阳后续职业阶段可接入同一套卡身。

文字区域为连续蓝黑底，不再按原版灰框分区；使用一个低对比日月星圆印。保留攻击、技能、能力各自的透明轮廓及原游戏布局，插图、费用、正文独立叠加，标题升级绿色继续由游戏管理。普通/基础/衍生/状态保留深色古金插图框；罕见原版青色、稀有原版金色贯通整圈插图框、类型小牌及整个顶部标题纹饰（含两侧卷尾）。普通类型小牌恢复原版灰色，所有类型字采用原版深色样式。

范围：19类自定义卡牌，包括5类初始、9类奖励、4类选择衍生牌与共舞，普通及升级版均适用。生成的原版碎屑、晕眩使用原版卡池外观；后续注册到本卡池的新牌自动沿用这套样式。

中文卡牌描述的数字及动态变量两侧不添加空格，例如 `造成{Damage:diff()}点伤害。` 显示为“造成7点伤害。”。同时维护description与smartDescription；英文仍保留正常单词间空格，能量图标语法不变。

## 2. 配色

| 部位 | 暗部 | 亮部或强调色 |
|---|---|---|
| 卡身与文字区 | 墨蓝约 `#071322` | 孔雀青约 `#0e4f5d` |
| 外沿及细线 | 古金暗部约 `#63411b` | 古金约 `#d4a252`、少量高光约 `#fad88c` |
| 所有类型文字 | — | 原版黑色，透明度 `0.752941`，不加自定义描边或阴影 |
| 标题文字 | — | 原版暖白 `#fff6e2`，升级绿色由游戏管理 |
| 普通/罕见/稀有标题描边 | — | 原版 `#4d4b40` / `#005c75` / `#6b4b00` |
| 普通标题窄色带 | — | `#879da6` |
| 罕见标题、框与类型牌 | — | 原版青色材质；参考图标题主色约 `#78e0ee`、牌签约 `#76d7dd` |
| 稀有标题、框与类型牌 | — | 原版金色材质；参考图标题主色约 `#ffcd5f`、牌签约 `#ffc367` |

底纹强度参数为0.17，优先保证长描述可读；少量程序笔触与角星纹用于建立材质层次。保留原版透明轮廓，不在插图上覆盖色层；原图中的厚灰框和正文内凹明暗不再保留。颜色参数是shader端点，实际显示还受渐变、节点调色和明暗影响。

标题、类型字不再由本Mod补丁覆写字体、颜色、描边或阴影，完全交回原版。中文版两者使用 `res://themes/fonts/zhs/noto_sans_mono_cjksc_regular_shared.tres`，保留0.95字面缩放、基线偏移及MSDF设置。标题默认字号26、描边/阴影描边参数12、阴影偏移2/2及低透明度，描边颜色随稀有度变化；这些参数结合原版字体渲染，不能直接用其他字体的像素描边粗细替代。类型字字号16，各稀有度字色一致。

原版三个部件共用 `CardModel.BannerMaterial`。罕见材质使用 `h=1/s=1/v=1`，稀有使用 `h=0.563/s=1.198/v=1.14`，普通使用 `h=1/s=0/v=0.85`；`res://shaders/hsv.gdshader` 保留原纹理明暗并转换颜色。上表青/金是参考截图取样，不是将所有部件平涂成单一色值；本Mod只引用原材质，不修改共享资源参数或原版文件。

## 5. 概念方案与接入记录：三辰星仪

以下保留初期方案及实际绘图提示词；当前运行时采用第1—4节所述的原版稀有度材质与文字规则。

### 截图反馈

用户实测截图显示，首版仍保留厚重的原版灰色标题带、蓝灰框及正文内凹结构。重配色带来的改变有限，卡身尚缺少与三辰费用图标一致的视觉识别。

参考图可借鉴鲜明的卡身主色、统一的正文纹样，以及插图与正文之间明确的层次；不复制其他Mod的标志或正文图案。根据用户后续要求，罕见/稀有沿用参考图使用的原版青/金材质，三辰卡身主题继续保留。

### 构图与配色

| 部位 | 新版方向 |
|---|---|
| 卡身外沿 | 墨蓝 `#121a2c` 过渡至孔雀青 `#20545e`，两侧略亮、中央克制；保留圆角卡牌轮廓 |
| 边框 | 降低宽厚金属边的存在感；暗金 `#8e713e` 主边、旧金 `#c6aa68` 少量高光、内侧细阴影 |
| 标题带 | 墨蓝底、窄金沿，保留原版标题带形状；暖象牙白标题，小面积稀有度强调色 |
| 插图框 | 深色衬边加窄金属线，避免原版厚灰框压过画面；不侵入既有插图安全区 |
| 类型牌 | 深蓝小牌、细金沿、暖白字，统一材质 |
| 正文区 | 蓝黑 `#101725` 至 `#172234` 柔和过渡，消除厚内凹框感；暖白正文仍为最显眼元素 |
| 正文底纹 | 一个三辰星仪：黑月、金日、银色三星在同一圆印内，少量轨道弧连接；压低对比，不能遮挡文字 |

卡身装饰采用适度手绘色块与少量材质笔触，匹配费用图标的庄重感。边角只使用少量星仪刻线，不添加龙纹、宝石或繁复雕花。三阶段共用这套外观。稀有度强调色与游戏原版信息保持一致，改动标题带时同步检查升级显示。

正文底纹亮度与底色差先按约5%—8%尝试，再根据游戏内文字调整；不让日月星分别发光。稀有度色带须在缩小后仍清楚，不能缩成难辨的一像素线。

### 拟用概念图提示词

以用户提供的天蟾香炉卡牌截图为布局参照，重新设计一张《灵境行者》主题的完整卡面概念图。只改变卡身、边框、标题带、类型牌和正文底纹，保留香炉插图、黑月银星金日费用图标及卡牌排版。主题为“三辰星仪”，中式志怪的庄重神秘感，清晰手绘色块、适度笔触、克制的金属质感。

卡身由墨蓝过渡至孔雀青，两侧略亮；用暗金窄边及少量旧金高光建立层次，去掉厚灰金属边和正文内凹框。标题带保留原版轮廓，改为墨蓝底镶窄金边；类型小牌同样深蓝镶金。插图边框为深色衬边与窄金线，不覆盖香炉画面。正文区为平整蓝黑底，中央放置一个低对比三辰星仪圆印：黑月、金日与银色三星统一在同一印记中，少量轨道弧线连接。图案只作为隐约底纹，暖象牙白正文清晰可读。

标题文字“天蟾香炉”，类型文字“技能”，费用“1”，正文“给予所有敌人 3 层中毒。\n给予自己 2 层中毒。”。不添加其他文字、额外徽章、宝石、龙纹、浮夸雕花、强烈光晕或写实三维效果。不复制参考Mod的标志。正面平视单张卡牌，完整展示卡身，简洁中性背景。
