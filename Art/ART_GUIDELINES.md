# 卡牌插图规范

## 1. 原文依据

- 用户明确选定的美术方向优先于一般还原建议。目前嗜血之刃沿用v2/v3的短刃形态和鲜红血迹，放弃v4历史柳叶刀造型；以重新构图表达挥砍，不因轨迹问题取消动作主题。

- 绘制前搜索小说中的道具名称，优先小段阅读首次出现及前后外观描写，再按需补查后续使用表现；不整本读取。
- 记录出处以及形状、材质、颜色、大小、构造、使用表现。道具信息框不能代替正文外观描写。
- 原文明示特征优先保留；未说明部分可做克制补充，并在样稿记录中注明。不得随意添加眼睛、符文、骷髅、宝石或改变道具身份的结构。

## 2. 尺寸与构图

- 普通卡图目标250×190像素，横向25:19比例；生成大图也按该比例构图，生成尺寸不等于最终交付尺寸。
- 主体尺寸以游戏卡框内完整显示为准，不机械追求70%—80%占比。关键道具端点、鞋头和鞋跟等识别特征避开上方标题和下方斜边遮挡；长条道具可通过较平缓倾角或调整透视留出余量，但不把固定斜线作为所有卡图的默认构图。人物可以有意裁切，须保留理解动作所需的关节、接触部位或姿态；生成后必须检查实际余量。
- 按道具功能与使用场景选择动作、视角和景别，可采用正面、侧面、俯视、仰视、近景手部或腿部、局部受击等表现。避免反复使用左上到右下、左下到右上的同一摆放与视角；不为变化而牺牲道具辨识和小尺寸可读性。
- 将新图放回整套牌组对照，兼顾动作方向、视角、景别和主次位置的变化，使卡图呈现一场精彩战斗的不同片段。构图可以丰富，手绘笔触、明暗处理与背景复杂度仍保持一致；不要求每张道具都出现人物、动作或完整场景。
- 动作首先由真实受力接触面、重心、关节姿态和物体位移表达，再辅以少量轨迹和冲击笔触；不能把道具与受击者贴在一起充当攻击。红舞鞋踩踏应表现鞋底压向防御部位、受击者承受冲击的姿态，而非鞋尖贴到身体上。
- 道具动作通过整体旋转与位移表达，保持定稿器型、结构和比例。红舞鞋“鞋尖抬起”指整只鞋旋转，不单独折起前掌、不把足弓弯成直角；生成后须与定稿轮廓对照，核对鞋头、足弓、鞋跟及搭带没有扭曲。
- 局部动作或接触关系不合理时，允许调整姿态、鞋的角度或观察视角。“保留总体构图”只限定整体布局，不代表局部物体角度不可改变；不能为了保留摆放而牺牲动作可信度。
- 运动轨迹必须对应物体运动方向、转动支点及刀锋朝向，不能仅为填充背景添加弧线；缺乏合理依据时取消轨迹装饰或调整姿态，不以不合理弧线代替动作。
- 柳刃等具体器型需查找实物资料，区分同名器物；参考实物不能代替小说设定，推断及未明确细节应注明。
- 采用明确的主次与单一视觉焦点；适度透视、挥动轨迹或功能表现增强动作感，不强求每张道具都出现人物或动作。
- 背景简洁，可按构图使用色块、放射形状或少量笔触辅助动作与焦点，不固定采用斜向背景。避免无意义纹理与复杂场景。

## 3. 手绘风格

- 以清晰轮廓、果断色块、适度夸张和可见手绘笔触为基准，避免摄影感、三维渲染感和电影式灯光。
- 明暗以两三块大色面组织；细碎纹理和高光从简，最亮或最鲜明的位置集中到焦点。
- 怪异感优先来自原作外观及功能，特效不能掩盖主体。保持不同卡牌之间的笔触、饱和度和明暗处理一致。
- 卡图默认采用简洁抽象背景、少量宽笔触与大色块；涉及接地动作时只补充必要的地面色块或投影，不自动扩展为废墟、建筑、湿石路面、密集草叶等完整场景。绘制或改图前对照已定稿卡图的轮廓、色块与背景复杂度；需要时以定稿图作为风格参考，避免单张图转向写实场景插画。具体场景需求以用户明确选定的方案为准。

## 4. 配色顺序

1. 保留原文明确的主体颜色，首先保证主体与背景的明暗对比。
2. 根据道具气质选择背景色调；不按攻击、防御或稀有度强制分色。
3. 用少量强调色表现血迹、火焰、毒雾或星光等功能。

每张图以一个背景主色、主体固有色和一个强调色为基础。背景可以重复，不为每件道具强求新颜色。

| 候选背景色系 | 可表现的气质 |
|---|---|
| 深青、蓝灰 | 阴冷、锋利、灵异 |
| 暗紫、靛蓝 | 神秘、精神影响、星空 |
| 暖赭、米黄 | 奇趣、喧闹、生活物件 |
| 墨绿、灰绿 | 毒性、古旧、沉静 |
| 暗红、棕红 | 危险、追杀、压迫 |
| 灰蓝、暖灰 | 稳定、克制、辅助 |

色系仅为候选，以实际主体可读性为准；例如红色道具不必配红背景。

## 5. 输出与验收

### 能量图标尺寸

- 卡牌左上角及tooltip大图标：74×74像素，对应BigEnergyIconPath。
- 卡牌描述富文本小图标：24×24像素，对应TextEnergyIconPath。
- 2026-10-04核对[人物教程](https://tutorials.sts2modding.com/docs/04-ritsulib/04-14-add-new-character/)及本机原版SlayTheSpire2.pck：铁甲、静默、摄政大图标图集区域均为74×74；其他裁切图标区域加margin也为74×74。文本能量纹理CTEX头部宽高均24。
- PNG采用透明背景，大图标中央留给游戏叠加费用数字；文本小图标直接由74×74费用图标等比例缩放为24×24，保持相同构图、配色、纹样与透明背景，不单独绘制或重新排列。图像本身不含数字。以上是原版资源尺寸，不等于屏幕显示像素大小。
- 费用数字须在游戏内检查中央留白，避免描边及字形遮挡日月星符号。当前三辰图标使用26字号上限、暖象牙白普通费用与3像素棕黑描边；费用变化的绿色、红色及禁用灰色保留原版语义。位置与字号修正由代码处理，不把数字绘进PNG。
- 费用数字采用独立字体变体加粗（`VariationEmbolden`增加0.65），并在本地化字体刷新后应用，防止覆盖。字形搭配棕黑短阴影（`#100e0bdd`，右1/下2像素，阴影描边2像素）；不要用大范围阴影遮挡日月星，不修改游戏共享字体。
- 人工加粗可能使字形轮廓相交，与MSDF渲染组合产生黑色针孔。当前仅在费用字体及回退字体的独立副本中关闭MSDF，使用普通光栅化；检查数字0/1/2/3/X的内部填充及缩放效果，不以字体度量通过替代游戏内视觉验收。

- 用户确认定稿后，自动清理该道具旧版图片及失效导入配置、规范定稿文件名、同步说明、绑定正式卡图并编译部署，无需再次要求用户逐项指示。按文件删除规则逐个核对明确路径，保留有效说明与历史开发记录，不清理无关道具。定稿不自动授权Git提交。

- 2026-10-06用户取消绘图前审查提示词的步骤：接到绘制或改图要求后，按需求直接调用绘图工具，无需先展示提示词并等待确认。完整实际提示词、原文依据、美术补充及检查结果仍写入绘图记录；仅在关键需求或输入确实缺失时询问。历史记录中的提示词确认步骤不代表当前流程。

- 图片只含插图，不含卡框、文字、费用、标识或水印。
- 按原文核对、构图提示、生成样稿、小尺寸检查、游戏内验收的顺序推进；生成不代表已完成游戏内验收。
- 小尺寸与卡框预览须检查关键主体是否被遮挡、攻击或防御是否能从接触面与姿态读懂、轨迹是否符合动作；人物局部裁切须有意且不影响动作辨识。并排对照已定稿卡图，检查新图是否再次重复同一斜线、视角和景别，同时保持全套画风与背景复杂度一致。
- 涉及人物时，逐一核对手脚数量、左右肢体的连接、关节走向与受力接触面；遮挡须有可辨识的连接关系，不接受缺失、重复或连接错位的肢体。明确表现双臂防御时，须能确认两条手臂各自连接到两只手，不能仅凭护脸轮廓认定通过。鞋底踩踏还须确认鞋底朝向、落点与受击部位对应，不能只凭鞋与人物相邻认定动作成立。
- 美术母图按用途和资产归档到 `Art/Cards/<asset>/`、`Art/Relics/<asset>/`、`Art/Characters/<character>/<asset>/` 或 `Art/UI/<asset>/`，完整提示词、原文出处、美术补充和检查结果随资产记录。未定稿的新版本及比较稿放在资产内部的 `drafts/YYYY-MM-DD/` 下；确认定稿后按上述规则清理旧稿。目录与现有素材见 [美术资产索引](README.md)。
- 确认接入后使用正式卡图资源路径，Godot重新导入、导出并部署。概念图不进入游戏PCK。
- 卡框及文字区美术单独规划，不用插图细节弥补界面风格问题。
- 卡身与边框采用三辰共用配色：墨蓝孔雀青、古金细边、普通深色镶金标题与低对比日月星圆印底纹。罕见/稀有标题、插图框和类型牌直接使用原版青/金材质，保留原纹理折面与明暗；普通类型牌签为原版灰色。标题和类型字沿用原版字体、字色及稀有度描边，保留升级绿色及独立费用图标；整个专属卡池统一应用，具体参数与文件用途见 [CARD_STYLE.md](UI/card_style/CARD_STYLE.md)。
