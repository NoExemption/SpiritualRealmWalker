# 卡牌插图规范

## 1. 原文依据

- 用户明确选定的美术方向优先于一般还原建议。目前嗜血之刃沿用v2/v3的短刃形态和鲜红血迹，放弃v4历史柳叶刀造型；以重新构图表达挥砍，不因轨迹问题取消动作主题。

- 绘制前搜索小说中的道具名称，优先小段阅读首次出现及前后外观描写，再按需补查后续使用表现；不整本读取。
- 记录出处以及形状、材质、颜色、大小、构造、使用表现。道具信息框不能代替正文外观描写。
- 原文明示特征优先保留；未说明部分可做克制补充，并在样稿记录中注明。不得随意添加眼睛、符文、骷髅、宝石或改变道具身份的结构。

## 2. 尺寸与构图

- 普通卡图目标250×190像素，横向25:19比例；生成大图也按该比例构图，生成尺寸不等于最终交付尺寸。
- 主体尺寸以游戏卡框内完整显示为准，不机械追求70%—80%占比。长条道具使用较平缓倾角，关键端点置于中央区域，避免上方标题和下方斜边遮挡；生成后必须检查实际余量。
- 运动轨迹必须对应物体运动方向、转动支点及刀锋朝向，不能仅为填充背景添加弧线；缺乏合理依据时取消运动轨迹。
- 柳刃等具体器型需查找实物资料，区分同名器物；参考实物不能代替小说设定，推断及未明确细节应注明。
- 采用明确的主次与单一视觉焦点；适度透视、挥动轨迹或功能表现增强动作感，不强求每张道具都出现人物或动作。
- 背景简洁，但通过斜向色块、放射形状或少量笔触辅助动作方向。避免无意义纹理与复杂场景。

## 3. 手绘风格

- 以清晰轮廓、果断色块、适度夸张和可见手绘笔触为基准，避免摄影感、三维渲染感和电影式灯光。
- 明暗以两三块大色面组织；细碎纹理和高光从简，最亮或最鲜明的位置集中到焦点。
- 怪异感优先来自原作外观及功能，特效不能掩盖主体。保持不同卡牌之间的笔触、饱和度和明暗处理一致。

## 4. 配色顺序

1. 保留原文明确的主体颜色，首先保证主体与背景的明暗对比。
2. 根据道具气质选择背景色调；不按攻击、防御或稀有度强制分色。
3. 用少量强调色表现血迹、火焰、毒雾或星光等功能。

每张图以一个背景主色、主体固有色和一个强调色为基础。背景可以重复，不为每件道具强求新颜色。

| 候选背景色系 | 可表现的气质 |
|---|---|
| 深青、蓝灰 | 阴冷、锋利、灵异 |
| 暗紫、靛蓝 | 神秘、精神影响、星空 |
| 暖赭、米黄 | 奇趣、喧闹、生活物件 |
| 墨绿、灰绿 | 毒性、古旧、沉静 |
| 暗红、棕红 | 危险、追杀、压迫 |
| 灰蓝、暖灰 | 稳定、克制、辅助 |

色系仅为候选，以实际主体可读性为准；例如红色道具不必配红背景。

## 5. 输出与验收

### 能量图标尺寸

- 卡牌左上角及tooltip大图标：74×74像素，对应BigEnergyIconPath。
- 卡牌描述富文本小图标：24×24像素，对应TextEnergyIconPath。
- 2026-10-04核对[人物教程](https://tutorials.sts2modding.com/docs/04-ritsulib/04-14-add-new-character/)及本机原版SlayTheSpire2.pck：铁甲、静默、摄政大图标图集区域均为74×74；其他裁切图标区域加margin也为74×74。文本能量纹理CTEX头部宽高均24。
- PNG采用透明背景，大图标中央留给游戏叠加费用数字；文本小图标直接由74×74费用图标等比例缩放为24×24，保持相同构图、配色、纹样与透明背景，不单独绘制或重新排列。图像本身不含数字。以上是原版资源尺寸，不等于屏幕显示像素大小。
- 费用数字须在游戏内检查中央留白，避免描边及字形遮挡日月星符号。当前三辰图标使用26字号上限、暖象牙白普通费用与3像素棕黑描边；费用变化的绿色、红色及禁用灰色保留原版语义。位置与字号修正由代码处理，不把数字绘进PNG。
- 费用数字采用独立字体变体加粗（`VariationEmbolden`增加0.65），并在本地化字体刷新后应用，防止覆盖。字形搭配棕黑短阴影（`#100e0bdd`，右1/下2像素，阴影描边2像素）；不要用大范围阴影遮挡日月星，不修改游戏共享字体。
- 人工加粗可能使字形轮廓相交，与MSDF渲染组合产生黑色针孔。当前仅在费用字体及回退字体的独立副本中关闭MSDF，使用普通光栅化；检查数字0/1/2/3/X的内部填充及缩放效果，不以字体度量通过替代游戏内视觉验收。

- 用户确认定稿后，自动清理该道具旧版图片及失效导入配置、规范定稿文件名、同步说明、绑定正式卡图并编译部署，无需再次要求用户逐项指示。按文件删除规则逐个核对明确路径，保留有效说明与历史开发记录，不清理无关道具。绘图仍需预先确认提示词；定稿不自动授权Git提交。

- 每次生成或编辑图片前，先向用户输出拟用提示词，得到明确确认后再调用绘图工具；确认只适用于该次提示词，不自动授权后续改图。

- 图片只含插图，不含卡框、文字、费用、标识或水印。
- 按原文核对、构图提示、生成样稿、小尺寸检查、游戏内验收的顺序推进；生成不代表已完成游戏内验收。
- 概念图保存到Art/Concepts下，完整提示词、原文出处、美术补充和检查结果随稿记录；新版本保留旧稿。
- 确认接入后使用正式卡图资源路径，Godot重新导入、导出并部署。概念图不进入游戏PCK。
- 卡框及文字区美术单独规划，不用插图细节弥补界面风格问题。
